# TiU Trails

A small, static React prototype for discovering hiking trails and mountain
cabins in Utopia. It is a student project for the University of South-Eastern
Norway (USN); the sample content is not connected to a backend.

## Run locally

```powershell
cd .\butikk-klient-0
npm.cmd install
npm.cmd run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the prototype.
